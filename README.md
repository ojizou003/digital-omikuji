# デジタルおみくじ 🎋

デジタルおみくじは、日本の伝統的なおみくじをウェブアプリケーションとして再現したStreamlitアプリケーションです。古典的な和歌や漢詩とともに、日々の運勢を占うことができます。

## 概要

このアプリでは以下の機能を提供しています：

- 日付表示：今日の日付と曜日（日本語表記）を表示
- おみくじ機能：ボタンを押すと100種類のおみくじからランダムに一つを引く
- 結果表示：運勢、和歌/漢詩とその現代語訳を表示
- 詳細表示：願望、待人、失物など10項目の運勢の詳細を確認可能
- サイドバー：おみくじの背景説明とバージョン情報

## 必要条件

- Python 3.11以上
- Streamlit 1.45.0以上
- pandas 2.2.3以上

## インストール方法

```bash
# リポジトリをクローン
git clone https://github.com/ojizou003/digital-omikuji.git
cd digital-omikuji

# 必要なライブラリをインストール
pip install -r requirements.txt
```

## 使用方法

1. 以下のコマンドでアプリを起動します：

```bash
streamlit run app.py
```

2. ブラウザが自動的に開き、アプリが表示されます
3. 「おみくじを引く」ボタンをクリックして運勢を占います
4. 「詳細」をクリックすると、より詳しい運勢の内容が表示されます

## データについて

おみくじのデータは `omikuji.csv` ファイルに保存されています。このCSVファイルには以下のカラムが含まれています：

- 運勢：大吉、中吉、小吉、吉、末吉、凶など
- 和歌／漢詩：運勢に関連する古典的な和歌や漢詩
- 現代語訳：和歌や漢詩の現代語訳
- その他の運勢項目：願望、待人、失物、旅行、商売、学問、争事、恋愛、転居、病気

## カスタマイズ

おみくじの内容をカスタマイズしたい場合は、`omikuji.csv` ファイルを編集してください。CSVファイルのフォーマットを維持しながら、内容を変更することができます。
